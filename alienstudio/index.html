      editing your show

      • click a ruler or empty cell to set the preview time.
      • select a block, then drag to move. drag either edge to resize.
      • drag across empty cells to draw a new block.
      • double-click a block or choose edit for its parameters. double-click an empty cell to create a block.
      • drag the playhead to inspect any time. Ctrl+wheel zooms around the pointer.
      • edit technical names and descriptions directly in track rows.
      • click an element row to edit its mix. + adds, * multiplies, - subtracts.
      • Ctrl+c / Ctrl+v copies a block to the selected track at the playhead.
      • delete removes a selected block. Ctrl+z undoes changes.
      • space plays or pauses. Ctrl+s downloads the current JSON.
      • select an element in the list or schematic to edit its mapping.
      • first pixel and count assign a consecutive range. physical pixel indices start at zero.
      • use start -1, start +1, reverse, or pick start on preview to set orientation.
      • use the advanced pixel list for a nonconsecutive logical order.
      • each physical pixel can belong to only one logical element.
      • open and save apply to mapping. Ctrl+s downloads its JSON.
      • undo and redo share the workspace history with the show editor.
      • playback and timeline zoom are available in the show editor.

      sound is optional. load a four-channel mod in show settings. connect through the local studio server to view device status and shows.
